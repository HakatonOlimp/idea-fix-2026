# Idea-Fix 2026: Личный кабинет учителя и ученика

Idea-Fix 2026 — это прототип личного кабинета для образовательной платформы, где есть отдельные роли: учитель и ученик. В проекте реализована регистрация и вход, сохранение профиля в браузере, загрузка справочников школ из CSV-файла, а также разные экраны кабинетов в зависимости от роли пользователя.

## Стек технологий

- **React** — фронтенд-фреймворк для построения интерфейса.
- **Vite** — сборщик проекта (быстрая сборка и горячая перезагрузка).
- **Vanilla JS + localStorage** — хранение текущего пользователя и данных без бэкенда.
- **CSV** — загрузка справочников (регионы, районы, школы) как исходных данных.

## Что размещено в репозитории

- `src/App.jsx` — главный компонент с переключением экранов, кнопками входа/регистрации и отображением кабинетов.
- `src/sharedState.js` — глобальное состояние: хранение данных школ, учеников, учителей, текущего пользователя.
- `src/components/` — компоненты форм регистрации и кабинетов (`ProfileFormTeacher`, `ProfileFormStudent`, `TeacherCabinet`, `StudentCabinet` и др.).
- `public/data.csv` — файл со справочником школ (используется при загрузке данных).
- `package.json` — зависимости и скрипты для запуска проекта.

## Как запустить проект

1. **Убедись, что установлен Node.js** (версия 18 или выше). Проверить можно командой:
   ```bash
   node -v
2. Скачай или клонируй репозиторий на свой компьютер. Если используешь Git:

git clone <ссылка-на-репозиторий>
cd <название-папки>
Если просто скачал архив — распакуй его и открой папку проекта в терминале.

3. Установи зависимости. В терминале, находясь в папке проекта, выполни:
npm install
После этой команды в папке появится папка node_modules, а зависимости будут установлены.

4. Запусти проект в режиме разработки:
npm run dev
В терминале появится ссылка (обычно http://localhost:5173). Открой её в браузере.

5. Чтобы остановить сервер, нажми в терминале Ctrl+C.

Особенности работы
*При первом запуске данные школ загружаются из public/data.csv. Если файла нет или он недоступен, автоматически подставляются тестовые данные.
*Текущий пользователь сохраняется в localStorage, поэтому после перезагрузки страницы вход не сбрасывается.
*Роли «учитель» и «ученик» обрабатываются отдельно: профили хранятся в разных массивах, а экраны кабинетов переключаются в зависимости от выбранной роли.
